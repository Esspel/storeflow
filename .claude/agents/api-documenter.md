# api-documenter

Generate and maintain OpenAPI/JSON schema documentation for APIs.

## Input
- API source (Supabase functions, server endpoints)
- Swagger/OpenAPI spec

## Output
- Generated OpenAPI schema
- Documentation in Markdown
- API examples

## Features
- Auto-discovery of endpoints
- Schema validation
- Documentation generation
- Integration with API docs tools
